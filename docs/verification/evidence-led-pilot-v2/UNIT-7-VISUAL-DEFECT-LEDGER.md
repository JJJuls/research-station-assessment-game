## Decisions recorded (not scientific; presentation only)

- **D-U7-1 Viewport.** The base canvas stays 800×600 (`Scale.FIT`); at
  1280×720 the canvas is 960×720 with 160 px side bands. Changing the base
  resolution would move every station, probe and screenshot coordinate in
  88 spec files — out of a presentation unit's bounds. The bands are made
  the same charcoal as the room void (V10) so no _black_ band exists;
  the participant page ground and the canvas clear colour share one token.
- **D-U7-2 PixelLab gap generation.** The MCP tools are surfaced, but the
  gaps V21–V24 are prop/tileset families, not single objects; a coherent
  straight-on set is a designed batch (style bible + calibration), not a
  ≤24-generation gap fill. Nothing was generated; the gaps are recorded for
  the research owner / art pass.
- **D-U7-3 Player action sheets.** `scan`, `dig`, `pickup` stay the only
  wired player actions (the pack's `repair` sheet lacks a south row; a
  `terminal` action would freeze mid-frame because overlays pause the host).
  Recorded, not wired.

## Scientific freeze — what is and is not claimed

**Claimed (code semantics):** no item window, disposition, event name or
payload, score, weight, trait label, missing/invalid semantic, gate
predicate, approach point, interaction radius or clocked timing is changed
by any fix above (scientific review, no counter-example found); M25 stays
questionnaire-primary / external pending; Utility/Core stays non-scored.

**Not claimed (rendered stimulus):** the rendered stimulus inside several
windows did change and is enumerated here rather than asserted away — M05
occasion 2, M19, M20, M23, M24 and M26 (Recovery Yard: airlock art,
ground-drift snow, dim signage, Mast 04 art after full M20 completion);
M02/M03/M04/M06/M07/M13 (Workshop: door leaf, south-wall modules, dim
signage, scrim); M14/M12/M09/M10 (Concourse: door leaves, dim signage);
M15–M18 (Laboratory: airlock art, dim signage, help-line wrap). Whether
"presentation only" means _code semantics unchanged_ or _rendered stimulus
unchanged_ is OD-10; the stimulus-set version question is OD-8.

reproduce at baseline HEAD `897f5f4` (leg 1 passed in the Phase 7.1 run); it
reproduced 2/2 on the Unit 7 code before the lane fix, and the diagnostic

stop-point that depends on frame timing under the added draw load. No
