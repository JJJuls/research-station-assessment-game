**In-implementation additions/decisions (documented before the edits were
made, per the no-silent-expansion rule):**

- `src/fieldActions/fieldActionLog.ts` — one new file INSIDE the unit's own
  new area. Discovery during testing: the Playwright CJS transform cannot
  import any module whose chain reaches `src/systems`/`import.meta`, and the
  repository's own measurement modules are therefore import-free (the
  CoolantYard ↔ m23Excavation division: the SCENE owns validity-register and
  runtime wiring). The opportunity adapters and generic telemetry were
  refactored to match that convention: they emit through an injected log
  sink (installed by the scene with `researchRuntime.logInteraction`), and
  all validity-register bookkeeping moved into `FieldActionsLabScene` —
  exactly where CoolantYard keeps it for the legacy M23/M24/M26 modules.
- **Lab map conforms to the single-screen-width room convention.** The
  first layout (30×22, horizontally scrolling camera) surfaced a base-class
  assumption: RoomScene's interact prompt clamps world-X to the 0-638
  viewport band, so any interactable east of ~600 px renders its prompt
  displaced once the camera scrolls horizontally. Every existing room is
  ≤800 px wide with stations ≤~620 px. The lab was rebuilt as 25×30
  (playable cols 1-19, east cols 20-24 wall mass under the right UI column —
  the CoolantYard viewport-filler precedent rotated vertically), scrolling
  vertically only. This consumed the unit's bounded visual correction round.

## 4. Input-safety decisions (recorded before implementation)

- All new keyboard handlers use `guardKeyHandler` + `event.repeat` checks.
- C/D/F eligibility = `RoomScene.physicalInputEligible()` (prompt open,
  typewriter, transition, active world action → all suppress).
- The inventory overlay suppresses everything structurally (host scene
  paused); resume resets latched keys (`openOverlay.ts` wiring).
- The magnet cycle holds the manual world-action bracket for its entire
  active span, so scans/digs/prompts/movement are impossible mid-cycle;
  keyboard (F/SPACE) and pointer lock routes converge on one
  `commitLock(source)` transition function.
- The scan cooldown is controller state (cooldown refusals are neutral
  feedback, never a modal).
