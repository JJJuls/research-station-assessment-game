# Canonical Room and Minigame Contracts (playable blueprint)

Documentation only; base `bfca741`. These contracts refine V3 §4 and the room
docs (`docs/game/rooms/`) under the tier-2 measurement specification. Event
names: **approved** = `docs/research/event-schema.md`; anything marked
CANDIDATE needs an event-schema decision; all new derived variables need a
scoring-plan decision. Every minigame below is a real interaction (objects,
placement, sequences, observable acts) — never a disguised multiple-choice
questionnaire item, and no player-facing text may restate Q wording.

Global contract rules (apply to all modules):

- Interaction model: proximity station (72 px), SPACE prompt, deterministic
  numbered options, chained stages (existing RoomScene machinery), extended
  by object-level interactions where specified.
- Opportunity flags: every module logs entry, station/prompt opened, and
  task availability so no-opportunity is distinguishable from
  non-performance; comprehension/technical states per DataQualityTracker.
- Interruption/return: leaving mid-task and re-entering must be classified
  (abandon/return family) wherever the module defines it.
- Accessibility: keyboard-first, no colour-only signals, concise text,
  no time pressure unless experimentally intended, viewport contract per
  `participant_viewport_display.spec.ts`.
- Definition of done (all modules): build + `lint:tsc` green; room's
  Playwright spec(s) green asserting event order + pinned
  `study_item_ids`/`construct_id`; no regression in journeys; research-data
  - gameplay + browser-QA reviews run.

## SM1. Shared goal-horizon module (HOR) — BLOCKED on SA-3

One balanced choice (ideally twice, counterbalanced) between a
self-contained objective with immediate closure and a distributed objective
of comparable total effort/value with late closure. Placement: after
mechanics comprehension, **before** the Interruption Corridor (initial
choice logged pre-interruption); natural host = Engineer Hub planning
terminal or Hub duty board. Options never labelled short/long-term; matched
on effort, value, difficulty, risk, attractiveness, social approval; the
distributed option must not read as virtuous. Feeds Q29+Q31 as ONE shared
variable; weak derived evidence for Q32; portfolio input for Q33. All
events (`horizon_choice_offered`, `immediate_goal_selected`,
`distributed_goal_selected`, …) and the single `goal_horizon_preference`
variable are CANDIDATES — implementable only after SA-3 (events + scoring).
Playwright acceptance (post-SA-3): both options chosen across two runs;
pre-interruption ordering asserted; balance metadata pinned; exactly one
horizon variable in summary.
